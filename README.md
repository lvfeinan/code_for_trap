# Analysis Code for Climate-Conflict Study
This repository contains the core Python code for the manuscript currently under peer review, which investigates the climate-conflict relationship. The scripts implement our primary analytical pipeline: data sampling, modeling, Propensity Score Matching (PSM), and statistical analysis.
